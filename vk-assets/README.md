# VK Game Images

Upload each PNG to the matching VK Games field:

- `universal-icon-576.png` - universal icon, 576 x 576 px.
- `catalog-icon-278.png` - catalog and snippets icon, 278 x 278 px.
- `small-icon-150.png` - small icon, 150 x 150 px.
- `favicon-32.png` - simplified browser favicon, 32 x 32 px; 1.25 KB.

The icon set is derived from the game's existing `icon.png` artwork to keep VK branding consistent with the game.
